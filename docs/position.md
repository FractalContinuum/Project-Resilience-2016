# Position

代表は、当時の状況について、自己を完全な加害者とも完全な傍観者とも位置付けていない。

実際には、S氏による指示・圧力・情報統制の下で、他者の借入れ・返済調整・集客等に関与させられ、その後、自身も法的・経済的リスクを負う立場となった。

一方で、問題発覚後は、

- 被害最小化
- 関係者対応
- 証拠保全
- 法的整理
- 債務整理

を優先し、自らも責任を一部負う形で対応を継続した。

本Repositoryは、「自己正当化」を目的とするものではなく、当時の構造と、その後の整理過程を一次情報ベースで残すことを目的としている。

※本Repository内において「代表」とは、当リポジトリの管理者であり、一連の法的整理および証拠保全を主導する本人を指す。
