# 趣旨

株式会社ジェーシービーに対する民事訴訟手続における書類を適切な処理の上、公開する。

本ディレクトリに掲載する書類は、裁判所提出書類を基礎とした公開用資料であり、個人情報、第三者情報、住所、連絡先、契約番号、担当者名等については、必要に応じて墨消し処理を行っている。

本公開は、係争相手への攻撃を目的とするものではなく、Project-Resilience-2016の目的である事実整理、証拠保全、説明責任、将来的な誤解・誹謗中傷へのカウンターエビデンス構築の一環として行う。

本件は公開された司法手続を通じて法律関係の整理を求めるものであり、原告は、提出済み書類についても、第三者情報に配慮した上で公開し、経緯の透明性を確保する方針である。

なお、甲号証については、甲第７号証を除き、本Repositoryのevidenceにて公開をしているものである。
