# JCB Civil Litigation

## 趣旨

株式会社ジェーシービーに対する民事訴訟手続における書類を、適切な処理の上、公開する。

本ディレクトリに掲載する書類は、裁判所提出書類を基礎とした公開用資料であり、個人情報、第三者情報、住所、連絡先、契約番号、担当者名等については、必要に応じて墨消し処理を行っている。

本公開は、係争相手への攻撃、名誉毀損、圧力行使、又は私的制裁を目的とするものではなく、Project-Resilience-2016の目的である事実整理、証拠保全、説明責任、制度観察、本人訴訟過程の記録化、ならびに将来的な誤解・誹謗中傷へのカウンターエビデンス構築の一環として行う。

本件は、公開された司法手続を通じて法律関係の整理を求めるものであり、原告は、提出済み書類についても、第三者情報に配慮した上で公開し、経緯の透明性を確保する方針である。

なお、本ディレクトリに掲載される資料および説明は、原告の提出資料および原告の認識に基づくものであり、裁判所、被告、行政機関、信用情報機関、又は第三者機関の公式見解を示すものではない。

本Repositoryに掲載する資料は、公開用に処理した写し又は整理資料であり、原本、未処理資料、個人情報を含む資料、第三者情報を含む資料については、原則として公開しない。

本件に関する記述は、原告の認識、提出資料、時系列整理に基づくものであり、今後の裁判所の判断、被告の主張、提出証拠、手続進行により、必要に応じて更新される可能性がある。

なお、甲号証については、`令和８年３月１３日以降の時系列表`を除き、本Repositoryの`/evidence/`にて公開しているものである。
