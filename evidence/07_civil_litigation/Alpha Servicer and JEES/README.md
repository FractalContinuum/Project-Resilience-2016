# Alpha Servicer and JEES Civil Litigation

## 趣旨

本ディレクトリは、アルファ債権回収株式会社および公益財団法人日本国際教育支援協会に対する民事訴訟手続に関連して、原告が裁判所へ提出した書類および関連資料を、適切な処理の上で公開するためのものである。

本ディレクトリに掲載する資料は、裁判所提出書類を基礎とした公開用資料であり、個人情報、第三者情報、住所、連絡先、契約番号、奨学生番号、担当者名、電話番号、口座情報その他の秘匿すべき情報については、必要に応じて墨消し処理を行っている。

本公開は、係争相手への攻撃、名誉毀損、圧力行使、又は私的制裁を目的とするものではなく、Project-Resilience-2016の目的である、事実整理、証拠保全、説明責任、制度観察、本人訴訟過程の記録化、ならびに将来的な誤解・誹謗中傷に対するカウンターエビデンス構築の一環として行うものである。

本件は、公開された司法手続を通じて法律関係の整理を求めるものであり、原告は、提出済み書類についても、第三者情報に配慮した上で公開し、経緯の透明性を確保する方針である。

なお、本ディレクトリに掲載される資料および説明は、原告の提出資料および原告の認識に基づくものであり、裁判所、被告ら、又は第三者機関の公式見解を示すものではない。


なお、甲号証については、`奨学生証`を除き、本Repositoryの`/evidence/`にて公開しているものである。
