# Project-Resilience-2016

Archival and case-study repository documenting long-term economic, debt, credit-information, collection, administrative, and judicial processes originating from events surrounding 2016.

本Repositoryは、2016年前後に生じた第三者による支配・指示等の影響下で発生し、又はその影響を受けた経済的・債務的問題について、その後の信用情報、債権管理回収、行政対応及び司法手続を含む長期的経過を整理・記録・公開するものです。

本資料の目的は、感情的告発又は特定個人・組織への攻撃ではありません。

時系列に基づく事実整理、証拠保全、将来的な検証可能性の確保、並びに将来的な誤解・事実誤認・誹謗中傷に対するカウンターエビデンスの構築を目的としています。

## Scope

本Repositoryは、特定の金融機関又は単一の債務問題のみを対象とするものではありません。

2016年前後の事実関係を起点として、その後に発生し、又は関連性が認識された経済的問題、債務関係、信用情報、債権管理回収、行政対応及び司法手続を記録対象とします。

初期整理では、主として信用情報機関の開示情報その他の当時確認可能な資料を起点として、対象となる企業及び債務関係を抽出していました。

そのため、信用情報上で直接確認できなかった債権又は、当初その関連性を認識していなかった事案については、初期スコープに含まれていない場合があります。

2026年6月、日本学生支援機構の奨学金に由来する求償債権について、公益財団法人日本国際教育支援協会及びアルファ債権回収株式会社との間で具体的な債権回収問題が顕在化しました。

その後、過去の経過を再検討した結果、当該奨学金の返還停止についても、2016年前後の経済状態及び生活状況との連続性があることを再認識したため、関連する債権管理回収及び司法手続を本Repositoryの記録対象に追加しています。

本Repositoryは、初回公開時点ですべての関連事象を認識していたことを前提としません。

新たな資料、事実又は過去事象との関連性が確認された場合、その経過を記録した上で対象範囲を更新します。

## Repository Structure

### `/docs/`

事案全体について整理、分析及び説明を行う公開文書。

* `overview.md`
  全体概要

* `chronology.md`
  時系列整理

* `position.md`
  Repository作成者自身の立場整理

* `analysis.md`
  行政、信用情報、債権管理回収その他の分析

* `structure.md`
  問題構造及び事象間の関係整理

* `disclosures.md`
  公開方針及び匿名化方針

* `status.md`
  現在状況の整理

* `legal-notice.md`
  法的注意事項

### `/evidence/`

公開可能な証拠資料及び関連記録。

証拠資料は、内容及び機能に応じて分類しています。

* `00_submissions_to_authorities/`
* `01_general_communications_redacted/`
* `02_content_certified_mail_redacted/`
* `03_cic_redacted/`
* `04_company_letters/`
* `05_administrative_dialogue/`
* `06_delivery_certificates/`
* `07_civil_litigation/`

詳細は `/evidence/README.md` を参照してください。

### `/raw/`

公開文書を構成する前段階の一次的な整理資料。

* `timeline.md`
  時系列情報の基礎整理

* `訴訟書面等の草稿・母稿`
  公開文書・提出文書の作成過程における一次的整理資料

`raw`配下の資料は、完成した分析又は確定的評価を示すものではありません。

## Purpose

本Repositoryの主な目的は以下のとおりです。

* 事実関係及び長期的経過の整理
* 証拠及び一次資料の保全
* 将来的な検証可能性の確保
* 誤解、事実誤認又は誹謗中傷に対するカウンターエビデンスの構築
* 債務、信用情報及び債権管理回収過程の可視化
* 行政及び司法手続を含む制度運用の記録
* 個別事案から確認された構造的問題の検討

本Repositoryは、過去の行為又は債務について、一方的な正当化又は責任回避を行うことを目的とするものではありません。

各債務関係、企業対応及び制度運用については、それぞれの事実関係及び法的関係を個別に検証します。

## Documentation Policy

掲載内容は、当時の記録、送付資料、電子メール、SMS、信用情報開示資料、企業又は行政機関から受領した書面及び法的手続等に基づいて構成します。

事実、推論及び評価は可能な限り区別します。

新たな資料又は事実が確認された場合、過去の記載を修正又は更新することがあります。

過去の認識と現在の認識が異なる場合、その変更自体も検証対象となり得るため、可能な範囲で更新経過を保持します。

## Disclosure and Privacy

個人情報及び第三者のプライバシーについては、公開目的との必要性及び相当性を検討した上で、匿名化、墨消し又は非公開化を行います。

公開情報である法人名、法人所在地、代表者その他の情報については、事案の理解及び検証に必要な範囲で掲載する場合があります。

担当者その他の自然人に関する情報については、原則として必要な匿名化を行います。

原本又は非匿名化資料は、証拠保全及び将来的な検証のため非公開で保管します。
